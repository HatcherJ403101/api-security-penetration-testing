# Assessment Evidence

This folder contains sanitised screenshots supporting the API security investigations.

Screenshots document the requests, responses and observed behaviour from the local OWASP crAPI training environment.

Before publication, all sensitive information must be redacted, including:
- Bearer tokens and session cookies
- Vehicle identifiers and VINs
- PINs and passwords
- Names and email addresses
- Latitude and longitude values

Only evidence necessary to explain the security finding should be published.
